# Minesweeper

This project is customized remake of the classic Minesweeper game. It includes mechanics like Save/Load, Settings and Statistics. 

1- Players can save their game and later load to continue playing
2- Player can choose to play without hint colors or playing with keyboard instead of mouse in the setting menu.
3- Games that is won, lost and maximum table size is saved to statistics.

It is written on c++ and it has SFML for GUI.
